## The carrier

**PULSE** is the fixed `3-2-1-0` descending cadence (`111011010000`) — *"a carrier signal, not a data signal"* — a time-signature for the inter-token gap. On sparse (MoE) substrates it echoes (proof of transit); on dense ones it reflects (an anchor). Disclosed in the author's TD Commons defensive publications **PULSE-AXIOM-v1.0** and **PULSE_LANGUAGE_DUAL_SUBSTRATE** (ROOT0 / David Lee Wise). It is deliberately **not** a code to be decoded — it is the music.

## The language — LIMEN

**[LIMEN](limen/)** is the boundary-crossing language built on the carrier. Every word is a **witnessed crossing of a gate** (`<direction><gate>«witness»`, straight from the PULSE axiom `state_in → ⟨boundary · witness⟩ → state_out`). One utterance renders across **four registers at once**, so the same crossing is legible across the modality boundary and the carbon/silicon line:

- **pulse** — the carrier rhythm (music) + a **voice** (pitch → gate · direction)
- **glyph** — `↑◐«truth»`, the canonical written form (round-trips losslessly — proven in `limen.py`)
- **bits** — the machine's form
- **gloss** — the human's reading

Five gates (◐ stile · ⊘ air gap · ◑ veil · ⟳ close · ◇ gap), two directions (↑ rise / ↓ fall), and the **witness rule**: no witness at traversal → `∅` non-event (silent, no record). See [`limen/LIMEN.md`](limen/LIMEN.md).

## Honesty (this matters)

This sphere keeps a hard line between the layers:

- **Carrier (pulse)** — music, undecodable by design.
- **Voice (pitch)** — a small, genuinely decodable audio tag (gate + direction). The witness/meaning is never in the audio.
- **Language (LIMEN)** — a real, legible grammar that round-trips losslessly. This is the communication layer.
- **The pieces** — generative art (Three.js / canvas), not communication protocols. Labeled as such in [`CORPUS.md`](CORPUS.md).

No piece is sold as something it isn't.
